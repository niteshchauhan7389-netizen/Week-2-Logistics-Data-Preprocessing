# Week 2 – Logistics Data Collection, Cleaning and Preprocessing

## Student
Nitesh Chauhan

## Role
Logistics Data Analyst Intern

## Project Overview

This project demonstrates a complete data preprocessing workflow for logistics and supply chain analysis using Python.

A publicly available DataCo SMART Supply Chain dataset was selected as the reference dataset. A reproducible simulated dataset based on its logistics structure was used to demonstrate practical preprocessing techniques.

## Objectives

- Collect and understand logistics data
- Identify data-quality problems
- Handle missing values
- Remove duplicate records
- Correct invalid values
- Standardize categorical data
- Detect outliers
- Create logistics-related features
- Normalize numerical variables
- Validate the final dataset

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## Data Preprocessing Steps

1. Data loading and inspection
2. Data profiling
3. Missing-value detection and treatment
4. Duplicate removal
5. Data-type correction
6. Categorical value standardization
7. Invalid-value correction
8. Outlier detection using IQR
9. Logistics feature engineering
10. Min-Max normalization
11. Final validation
12. Export of cleaned dataset

## Key Features Created

- `delay_days`
- `sla_breach`
- `profit_margin_pct`
- `shipping_time_outlier`

## Outcome

The preprocessing workflow produced an analysis-ready dataset by addressing missing values, duplicates, invalid records, inconsistent categories, outliers, and numerical scale differences.

The project demonstrates how data quality directly affects logistics analytics and operational decision-making.
